# 知映（Zhiying）

> 让不会剪辑的人，也能把有用的知识做成易懂的视频。

社区反诈科普短片制作平台 · 本地原型 v0.4 · 纯本地运行，不接外部 AI

输入一份已核实的反诈资料，知映把它整理成可编辑的分镜，由你逐幕核对画面与表达，
再配上离线中文配音和大字幕，合成可以分享给长辈看的 MP4 短片。
目标使用者是社区工作人员和志愿者；观看者包括老年人，所以字幕要大、话要说明白。

**两点诚实说明：**

- 分镜整理是**本地规则**完成的，不是生成式 AI；系统不凭空补充事实。
- 隐喻画面（如"电量被消耗""思路被打断"）来自**道具库的人工选择**，系统只给初稿建议，最终由你决定。

## 功能一览

- **三步工作流**：整理资料 → 核对分镜 → 预览与导出，上一步未完成时下一步锁定。
- **渲染风格库**：浅色插画 / 夜色发光（暗色影院 + 发光线稿）两种风格，一键切换；
  切换时道具自动映射到目标风格的对应道具，并重置全部核对状态。
- **道具库（每幕自主选择）**：
  - 浅色插画 6 种情景：收到消息、陌生来电、转账风险、主动核实、留证求助、重点提醒；
  - 夜色发光 5 种隐喻道具：发光标题卡、能量电量表、思路叠层卡、代价票据、循环与计数。
- **道具参数可编辑**：叠层卡的步骤与红色打断字、电量起止百分比、票据条目（末条红色警示带）、
  计数目标与单位、标题副小字等；字幕支持最多 3 个关键词标红。
- **画面编辑**：可导入本地图片替换插画（裁剪、适配、焦点可调），可随时恢复插画。
- **听觉与预览**：逐幕离线试听、连续预览（画面动画与配音同步）、视觉时间线拖拽/键盘排序。
- **人工核对闸门**：任何内容、道具、参数、顺序的修改都会使该幕核对失效；全部核对通过才能导出。
- **导出**：1280×720 H.264 + AAC 的 MP4、SRT 字幕、文字脚本；导出后再编辑会使旧成片失效。
- **其它**：草稿自动保存在浏览器本地；三套界面主题与无障碍配音设置；移动端布局适配。

## 快速开始（Windows）

环境要求：

- Windows 10/11（配音依赖系统自带的中文语音，字体依赖系统微软雅黑/宋体）；
- Python 3.10 及以上（64 位）。

```bat
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe server.py --open
```

或双击 `配置环境.cmd`：自动挑选可用的 Python 3.10+（会跳过 PATH 里损坏的解释器），
建好 `.venv` 并装齐依赖；之后双击 `启动知映.cmd` 使用（默认走 `.venv` 并自动打开浏览器）。

服务只监听 `http://127.0.0.1:8765`，可用 `--port` 改端口。
依赖只有两个：Pillow（画面渲染）与 imageio-ffmpeg（自带 FFmpeg，用于合成 MP4）；
配音走 Windows System.Speech 离线中文语音，不联网。

## 使用流程

1. **整理资料**：粘贴已核实的资料（至少 20 字），选择渲染风格，点击整理分镜；
2. **核对分镜**：逐幕选择道具、编辑参数与字幕标红关键词，可换本地图片；
   用试听和连续预览检查效果，对照原资料逐幕确认；
3. **预览与导出**：全部核对通过后生成 MP4，并可下载 SRT 字幕与文字脚本。

## 项目结构

```
zhiying/
├─ server.py            # 本地 HTTP 服务：API、输入校验、配音调度、导出任务
├─ rendering.py         # Pillow 逐帧渲染：风格库/道具库、动画相位、发光合成、字幕
├─ speech.ps1           # Windows System.Speech 离线中文配音
├─ static/              # 前端页面（原生 HTML/CSS/JS，无构建步骤）
│  ├─ index.html
│  ├─ app.js
│  ├─ styles.css
│  └─ favicon.svg
├─ tests/
│  ├─ test_local.py     # 后端 unittest（44 项）
│  └─ browser-check.cjs # Playwright 浏览器回归（27 项）
├─ requirements.txt
├─ 配置环境.cmd          # 一键建 .venv 并安装依赖
├─ 启动知映.cmd          # 一键启动本地服务
└─ .gitignore
```

运行时产物目录（已 gitignore，不入库）：`assets/` 导入图片、`previews/` 预览缓存、
`auditions/` 试听缓存、`exports/` 导出成片。

磁盘卫生：导出成功后只保留 `video.mp4 / subtitles.srt / script.txt / render.log / project.json`，
逐帧 PNG、分段 wav、clip mp4 等中间文件即时删除；服务启动、每次合成完成和"预览与导出"页的手动
"清理旧成片与缓存"共用同一套策略——无 `video.mp4` 的半成品过 24 小时宽限期即删（正在制作的任务除外），
已完成成片最多保留 10 支且总量不超过约 1 GB，`previews/`、`auditions/` 按最久未使用修剪到 256 MB / 128 MB 以内。
删除项目时前端会计算引用差集，通过 `/api/gc` 删除该项目成片目录与不再被任何项目引用的 `assets/*.png`；
`/api/usage` 提供各目录占用，供页面展示。

## 设计要点

- **所见即所得**：预览与导出共用同一套 `draw_frame` / `animation_times` 渲染器，
  缓存键只取影响画面的字段（标题、配音、道具、风格、序号），勾选"已核对"或改原资料不会触发重渲染；
  每个缓存键配锁，并发请求只渲染一次，命中时抽查首尾帧文件、缺失自动重建。
- **库化与自主控制**：`STYLES`、`SCENE_KINDS`、`NOIR_KINDS` 是注册表而非写死分支；
  `STYLE_KIND_MAP` 负责切风格时的道具双向映射。新增风格/道具应进库并可切换。
- **动画**：`phase_starts(style, kind)` 定义每种道具的分阶段浮现相位；
  发光效果 = RGBA 线稿层 + GaussianBlur 光晕 + alpha 合成，逐相位淡入。
- **核对状态机**：编辑即失效（`reviewed=false`），导出前强制全幕人工核对，
  保证"AI 整理、人来负责"的公益内容底线。
- **安全边界**：仅监听 127.0.0.1；校验 Host/Origin 与自定义请求头；CSP 仅 self；
  图片格式与大小校验；前端一律 `textContent` 插入，杜绝注入。
- **导出管线**：逐幕帧序列经 ffconcat 拼接，libx264（yuv420p）+ AAC + faststart 封装 MP4。

## 运行测试

后端（44 项）：

```bat
.venv\Scripts\python.exe -m unittest discover -s tests -v
```

浏览器回归（27 项，可选）：脚本依赖本机安装的 `playwright-core` 与 Edge 浏览器，
需先把 `tests/browser-check.cjs` 顶部的 require 路径和 Edge 可执行文件路径改成你自己的环境；
先启动服务，再运行 `node tests/browser-check.cjs`，截图输出到仓库外的 `../截图/`。

## 边界与后续方向

- 纯本地运行：不接外部 AI、不向云端上传资料与图片；
- 目前仅 16:9 横屏 1280×720；竖屏 9:16、更多道具（如火柴人）、更自然的配音属于后续增量，尚未实施。
