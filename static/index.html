从资料到短片，只需三步

  1. 整理资料

    粘贴已核实的反诈资料，或载入演示示例；分段写清要点，并自主选择渲染风格库（浅色插画 / 夜色发光）。

  2. 核对分镜

    本地规则拆分原文并按关键词推荐道具，不核查事实。可在当前风格库中自主更换每幕道具、编辑道具参数（步骤、百分比、票据条目、标红关键词等）、导入本机图片并调整取景；在时间轴上拖动卡片或前移后移调整顺序后需重新核对全部内容。画面会随配音逐条呈现并高亮风险。

  3. 试听与导出

    可逐幕试听本机配音、连续预览动态草稿；确认后用 Windows 离线中文语音和本机 FFmpeg 制作真实 MP4，完成后可播放、下载视频和字幕。

项目保存在当前浏览器的本机项目库（IndexedDB），图片副本同时保存在 assets 目录，视频保存在 exports 目录；均不对外上传或发布。合成完成与服务启动时会自动清理超出保留上限的旧成片、半成品与预览配音缓存，也可以在“预览与导出”区查看本机占用并手动清理。删除项目会一并清理它的成片与未被其他项目引用的图片。清空草稿只影响当前项目，不会删除本地素材和成片。
